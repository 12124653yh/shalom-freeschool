# 샬롬자유학교 (Shalom Free School) 웹사이트

하나님의 형상을 회복하며 삶의 힘을 기르는 교육공동체, **샬롬자유학교**의 공식 소개 웹사이트입니다.

## 🌿 주요 특징 및 페이지 구성

- **메인 페이지 (`index.html`)**:
  - 시원한 풀와이드 Hero 섹션 (비율 왜곡 없는 고해상도 배경)
  - 3대 교육철학 (자유의 맛, 사랑의 멋, 대안의 삶)
  - 1년 3학기제 교육과정 프리뷰
  - 학교생활 및 학교 공동체 (학생 중심, 기숙 공동체, 지역 연대)
  - 공식 유튜브 채널 영상 카드
  - 자동 동기화 반응형 갤러리 (라이트박스 모달 지원)
  - 스크롤 인터랙션 애니메이션 (헤더 반응, 읽기 진행 바, 탑 버튼, 페이드/슬라이드 인)
- **교육철학 상세 페이지 (`philosophy.html`)**:
  - 샬롬자유학교의 3대 핵심 가치와 상세 철학 에세이
  - 하루의 흐름 및 가치 실천 안내
- **교육과정 상세 페이지 (`curriculum.html`)**:
  - 1년 3학기제 상세 안내 (1학기 기초, 2학기 방향, 3학기 대안)
  - 비폭력대화(NVC), 걷기 여행, 다중지능이론 & 사회참여학습, 몰입주간 및 인턴십 등

## 📁 디렉터리 구조

```text
├── index.html                   # 메인 랜딩 페이지
├── philosophy.html              # 교육철학 상세 페이지
├── curriculum.html              # 교육과정 상세 페이지
├── style.css                    # 통합 스타일시트 (자연스러운 그린&화이트 테마)
├── scroll-anim.js               # 스크롤 인터랙션 애니메이션 시스템
├── gallery_data.js              # 갤러리 사진 목록 자동 생성 데이터
├── update_gallery.js            # 갤러리 사진 실시간 감시 및 갱신 스크립트
├── 갤러리 샬롬 사진/           # 사용자가 직접 사진을 추가하는 폴더
└── images/                      # 웹사이트 리소스 및 배너 이미지
```

## ✨ 스크롤 애니메이션 시스템 (`scroll-anim.js`)
- 스크롤 위치에 반응하여 섹션 헤더 및 카드가 부드럽게 나타나는 순차적(Staggered) Reveal 효과
- 상단 스크롤 진행률 인디케이터 바
- 우측 하단 맨 위로 가기(Back to Top) 플로팅 버튼
- 접근성(`prefers-reduced-motion`) 대응 및 순수 자바스크립트/CSS 기반 최적화
